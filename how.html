The method

How a verdict is reached

VerifyAI doesn't ask you to trust it. Every verdict is built from live web sources you can open and read yourself.

  1. You submit a claimA statement you've seen online, or an image. Text is sent to the verification service; images are read for hidden metadata right in your browser and never uploaded.
  2. It searches the live webAn AI model with Google Search grounding composes several queries, reads what it finds, and looks specifically for primary sources and existing fact-checks.
  3. It weighs the evidenceThe model decides whether the claim is supported, misleading, false, or simply unverifiable — and how confident that judgement is.
  4. It returns a verdict with sourcesYou get a plain label, a confidence figure, the reasoning, and a list of the sources it relied on. If it can't find enough, it says so rather than guessing.

Checking an image

For images, VerifyAI reads the file's EXIF metadata in your browser — the capture date, camera, editing software, and GPS location if present. Recycled or AI-generated images often show editing software, mismatched dates, or no camera data at all. It also gives you one-tap reverse-image search links (Google Lens, TinEye, Bing) so you can find where a photo first appeared.

Important

Stripped metadata is normal — most social platforms remove EXIF on upload. Missing metadata is not proof of anything on its own; it's one signal among several.

What the labels mean

  • True — the claim matches the primary evidence located.
  • Misleading — partly true but framed to mislead: wrong context, outdated, cropped, or cherry-picked.
  • False — contradicted by the evidence, or no credible source exists.
  • Unverified — no adequate source could be located. VerifyAI will not invent a verdict.

Privacy

Image metadata is read locally and the image itself is never sent anywhere. Only the text of a claim is sent to the verification service to run the web search. There are no accounts and no tracking.
