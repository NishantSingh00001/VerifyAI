About

An honest verification tool

VerifyAI is a free, no-account tool that helps you check a claim or image against the live web before you share it — and shows its working.

What it does well

  • Checks factual, checkable claims against current web sources.
  • Surfaces primary sources and existing fact-checks you can read yourself.
  • Reads an image's hidden metadata to spot recycled or edited photos.
  • Gives a plain verdict with a confidence figure — and admits when it can't tell.

What it can't do — and its limits

Read this before you rely on a verdict

VerifyAI uses an AI model with web search. That means it can be confidently wrong, miss context, or lean on a weak source. It is a starting point, not a final authority.

  • Opinions and predictions can't be fact-checked — only verifiable claims about the world.
  • Breaking news is hard — sources may not exist yet; expect "Unverified".
  • It can't confirm an image is AI-generated — metadata is a hint, not proof. Use the reverse-image links too.
  • Source quality varies — always open the sources and judge them yourself.
  • It is not a substitute for professional fact-checkers or primary reporting.

How it's built

A static multi-page site with one small serverless function that calls Google's Gemini model with live Google Search. Image metadata is parsed in your browser. There is no database, no account system, and nothing you check is stored.
